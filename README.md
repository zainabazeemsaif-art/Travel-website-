Travel-website-Landing page 

 📌 About the Project
This project is a simple and responsive travel website landing page designed to showcase travel destinations and provide an attractive user interface for visitors.

The website is built using HTML, CSS, and Bootstrap, focusing on a clean layout, appealing design, and user-friendly experience.

 Technologies Used:
HTML5– For website structure.
CSS3 – For styling and customization.
Bootstrap – For responsive layouts and ready-made UI components.

 Features:
- Clean and attractive landing page design.
- Responsive layout using Bootstrap.
- User-friendly navigation.
- Travel-inspired design and visuals.
- Simple and organized front-end structure.
